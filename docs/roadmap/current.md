# Current Status

Mono v2.0 is live and operational.

## What's Working

- ✅ 3D box dimensions input (L × W × H in mm)
- ✅ 4 box styles with automatic flat size calculation
- ✅ 6 layout algorithms
- ✅ Algorithm comparison table
- ✅ Interactive Fabric.js canvas
- ✅ SVG and DXF export
- ✅ Flat dieline diagram with annotations
- ✅ 3D isometric box preview
- ✅ User guide sidebar
- ✅ FastAPI backend on Railway
- ✅ React frontend on GitHub Pages
- ✅ 32 unit tests — all passing
- ✅ Modular feature-based architecture
- ✅ PDF dimension extraction endpoint

## Known Limitations

- Tumble layout visual rendering needs further refinement
- PDF extraction works for text-based PDFs only — image-only PDFs not supported
- No user accounts or job history yet
- Sheet sizes not validated against known press sizes
