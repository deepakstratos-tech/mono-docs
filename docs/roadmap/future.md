# Future Roadmap

## Near Term

- PDF upload UI (Phase 1 — dimension extraction)
- Validate algorithms against real production data from Mayank's plant
- Fix tumble layout visual rendering
- L-shaped and Z-shaped carton support

## Medium Term

- User accounts with role-based access (Admin, Planner, Designer)
- Job history — save and retrieve previous imposition jobs
- Multi-SKU imposition — multiple carton sizes on one sheet
- Tier 3 algorithms from the research paper (Guillotine, 2-approximation)

## Long Term

- Subscription and payment module
- Job workflow — from planning to press approval
- Designer editor mode — drag cartons, adjust manually, save
- DXF dieline import for exact polygon nesting
- Genetic algorithm for AI-based layout optimisation
- Integration with MIS systems
